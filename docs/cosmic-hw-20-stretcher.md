# COSMIC-HW-20: «двое несут, третий подаёт»

HW-20 применяет принцип «носилок» к узкому месту HW-19 без покупки платы:

- два физических итеративных SHA-256 движка считают по одному раунду за такт;
- один полный блок ждёт в конечном буфере и подаётся первому освободившемуся движку;
- следующий набор из десяти квитанций может собираться параллельно;
- digest выводятся строго по порядку commitment sequence, потери и бесконечная очередь запрещены.

Третий слот — не третье вычислительное ядро. Он убирает простой между сборкой и диспетчеризацией, но не нарушает закон сохранения работы. Для 13 digest нижняя граница только SHA-раундов равна `ceil(13 / 2) * 64 = 448` тактов. Поэтому честный выигрыш относительно HW-19 с 862 тактами не может достигнуть 3×.

## Что проверяет контракт

`tools/cosmic_hw_20_stretcher.py` на точном исходном дереве:

1. повторяет 862-тактовый HW-19 x1 control;
2. исполняет тот же A→M→C workload на x2;
3. сверяет 128 квитанций, 13 digest и последний SHA-256 oracle;
4. доказывает, что оба физических движка принимали блоки;
5. требует наблюдать полный waiting slot, пока оба движка заняты;
6. синтезирует x2 core и ULX3S-85F wrapper без DSP;
7. при `--route` размещает, трассирует и пакует один ECP5 seed на 10 MHz;
8. сравнивает только модель RTL-циклов с измеренным single-thread CPU reference HW-19.

Локальный прогон после установки Icarus Verilog и Yosys:

```bash
python -m pytest -q tests/test_cosmic_hw_20.py
python tools/cosmic_hw_20_stretcher.py --output-dir build/cosmic-hw-20
```

Полный open-toolchain прогон с one-seed route:

```bash
python tools/cosmic_hw_20_stretcher.py \
  --route \
  --output-dir build/cosmic-hw-20
```

## Граница заявления

Симуляция, синтез и route не являются физическим измерением платы. HW-20 не устанавливает latency, throughput, power или energy на реальном ULX3S, не разрешает persistent flash и не заявляет превосходство над CPU. До измеренного среднего CPU HW-19 при 20.25 MHz модель должна уложиться не более чем в 113 тактов; два 64-раундовых ядра этого фундаментально достичь не могут.
