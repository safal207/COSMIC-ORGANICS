# Scientific Boundaries

COSMIC ORGANICS deliberately separates evidence from speculation.

## VERIFIED

The project may treat a statement as VERIFIED when it is supported by reproducible experimental literature or strong review literature and the repository records the source.

Examples relevant to the program include:

- phase-change materials can exhibit electrically/optically distinguishable amorphous and crystalline states;
- stateful material devices are researched for memory, in-memory, and neuromorphic computation;
- synthetic living materials can combine engineered biological functions with material matrices.

VERIFIED does **not** mean that COSMIC ORGANICS itself has reproduced the experiment.

## HYPOTHESIS

A statement is HYPOTHESIS when it is a falsifiable project proposition, for example:

- a compact algebra of state transitions can usefully describe multiple classes of material computation;
- mixed-state lattices can solve useful computational tasks through structural transitions;
- a graph of local transition rules can bridge simulation and later device calibration.

A hypothesis should identify a test capable of failing it.

## HORIZON

HORIZON labels long-range ideas that currently lack a direct proof path in this repository, including:

- autonomous self-reconfiguring physical neuro-systems;
- material computation that actively guides tissue-scale morphogenesis;
- organ fabrication enabled by COSMIC ORGANICS;
- quantum-biological computation without a specified measurable quantum mechanism.

Horizon ideas are welcome as research direction, but must not be presented as current capabilities.

## Claim rule

If a claim cannot yet be placed confidently into VERIFIED, it defaults to HYPOTHESIS or HORIZON—never upward.
