# С чего начать — COSMIC-ORGANICS

[Главная](README.md) · [Исследования](RESEARCH_INDEX.md) · [Правила](REPOSITORY_GUIDE.md)

## Хочу использовать

Начни с программного ядра и incident-map demo на main. Запусти `make verify` и `make demo` после установки проекта. Для этого не нужна физическая FPGA. Это reference для воспроизведения и разработки, не готовая замена CPU.

## Хочу исследовать

Открой RESEARCH_INDEX.md и выбери конкретную гипотезу. HW-22 — отдельный draft на закреплённом коммите, а не часть опубликованного main. Номер HW сам по себе не означает готовность или замену всех предшествующих профилей.

## Хочу понять, что уже доказано

Различай программную эквивалентность, RTL-симуляцию, синтез, размещение и трассировку, работу физической платы и сквозные измерения. Уменьшение числа вычислений узлов не равно такому же уменьшению времени или энергии.

Неудачный fit полного профиля и отрицательные сравнения сохранены. Это результаты исследования, а не мусор для удаления. Более узкий удачный профиль не отменяет старый отрицательный результат.

## Как поддерживать порядок

Код, тесты и результаты остаются на прежних путях. Старый README сохранён. Новая работа должна иметь один вопрос, закреплённую базу, сильный контроль, результат с хешами, ограничения и статус ревью. Ветки не удаляются до проверки уникальных коммитов, зависимостей PR и сохранности свидетельств.
